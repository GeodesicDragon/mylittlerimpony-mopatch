Version 1.30.18 (April 29th 2025)

* Core: Added a new recipe to the Stone Exchange which allows you to purchase clay blocks.
* Core: Added Granny Smith.
	* Acts as a sunlamp.
	* Does not require any power.
	* Can be researched after unlocking advanced agriculture.
	* Requires 250 steel, 125 iron and 10 basic components to build.
* Vanilla Achievements Expanded: Added an achievement to build Granny Smith.
* Core: Removed support for version 1.4 of RimWorld.
* Core: Removed all XML Extensions patches.
* Core: The recipe for herbal cure kits has been changed to 5 fleawort, 5 fly agaric, 5 herbal meds, 5 mindwort and 5 poppies (was 25 herbal meds).
* Core: Herbal cure kits can now be made at the alchemy workbench.
* Core: Herbal cure kits are now made in batches of 5.
* Core: Researching how to make herbal cure kits now requires you to research alchemy first.
* Core: Researching the Statues of the Evil Sisters now requires you to research smithing instead of biofuel refining.
* Core: Miss Harshwhinny now reduces temperature to a maximum of negative three degrees, but at the cost of using 25% more fuel.
* Core: Miss Harshwhinny can now be refuelled with coal, tar, raw dark wood, dark wood planks, and Medieval Overhaul's wooden logs.
* Core: Coal costs at the Daybreaker statue have been doubled.
* Core: Purchasing 500 of each block at the stone exchange now gives you clay blocks.
* Ideology: Fixed 'Verse.PatchOperationConditional(xpath=Defs/FactionDef[defName="MLRP_Batpony_Faction"]/disallowedMemes' error seen if Alpha Genes wasn't enabled.
* Biotech: Fixed 'Verse.PatchOperationReplace(xpath="Defs/FactionDef[defName="MLRP_Batpony_Faction"]/techLevel"): Failed to find a node with the given xpath' error seen if Alpha Genes wasn't enabled.
* Biotech: Fixed 'Verse.PatchOperationAdd(xpath="Defs/FactionDef[defName="MLRP_Batpony_Faction"]/caravanTraderKinds"): Failed to find a node with the given xpath' error seen if Alpha Genes wasn't enabled.
* Biotech: The Renegade Alicorn scenario now starts with 500 coal instead of 250 chemfuel.

Version 1.27.3 (January 20th 2024)

* If you have XML Extensions enabled, you can now decide whether or not the following changes are applied.
	* Aggro turrets require power.
	* Daybreaker requires coal instead of chemfuel.
	* Sweetie Bot requires 1000000W of power instead of 400W.
* Added patch which sets the player faction tech level to Medieval.
* Added patch which sets the NPC faction tech level to Medieval.
* Added patch which sets the batpony faction tech level to Medieval.
* Added patch which sets the renegade alicorn faction tech level to Medieval.
* Added patch which removes the need to power the Stone Exchange.
* Added patch which removes the need to power the Super Speedy Cider Squeezy 6000.
* Added patch which removes the need to power Nurse Redheart, and changes her to spawn herbal medicine instead of industrial.
* Added patch which removes the need to power the Fabric Exchange.
* Added patch which unlocks the Fabric Exchange after researching Tailoring.
* Added six new purchase recipes to the Fabric Exchange.
	* Linen (170 silver)
	* Silk (530 silver)
	* Daer leather (1790 silver)
	* Lindwurm scales (2100 silver)
	* Rox wool (290 silver)
	* Tanning liquor (230 silver)
* Added a patch for VFE Deserters which changes the regular intel recipe to require 50 herbal medicine instead of 25 industrial.
* Added a patch for VFE Deserters which changes the critical intel recipe to require 100 herbal medicine instead of 25 glitterworld.
* NPC factions - regular and batpony - will now send scholar caravans.

Version 1.7.2 (December 16th 2023)

* Added Daybreaker recipes to convert iron ingots into silver and vice versa.
	* 1000 silver can be turned into 667 ingots and back again.
	* No research required.
	* Uses 10 coal.
* Added Daybreaker recipes to convert vanilla components into Medieval Overhaul's basic components and vice versa.
	* Conversions are done at a 1:1 ratio.
	* Conversions do not use any fuel.
* Added patch which makes Mudbriar turrets require power.
* Added patch which makes Quibble Pants turrets require power.
* Added patch which makes Zephyr Breeze turrets require power.
* The plushie bench can now link to the tool rack.
